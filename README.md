# 🚀 AI Coding Skills & Guidelines

Repositori ini berisi kumpulan instruksi dan pedoman (**Skills**) eksternal yang dirancang khusus untuk AI Coding Agent.

## 🎯 Tujuan
Repositori ini berfungsi sebagai basis pengetahuan eksternal agar AI dapat bekerja dengan konteks yang mendalam dan memberikan hasil yang sesuai dengan ekspektasi tinggi user.

- **Konteks User**: Memberikan pemahaman mendalam tentang standar kualitas yang diinginkan.
- **Ekspektasi Output**: Memastikan AI menghasilkan desain premium, arsitektur profesional, dan kode yang maintainable.
- **Anti-Generic AI**: Menghindari pola "AI-isms" (kode generik, boilerplate berlebihan, dan struktur dangkal).

## 📂 Struktur Direktori

| Folder | Deskripsi |
|--------|-----------|
| [`web/`](file:///web/) | Panduan komprehensif untuk pengembangan Web (Frontend, Backend, & Database). |

## 🛠️ Cara Penggunaan
Bagi AI Coding Agent yang mengakses repositori ini, instruksi utama dapat ditemukan di dalam folder masing-masing domain (misalnya di [`web/README.md`](file:///web/README.md)).
